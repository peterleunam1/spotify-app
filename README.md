# Spotify Insight

A modern web application that lets you explore your Spotify data in a clean, interactive, and visually engaging way. Discover your listening habits, favorite artists, albums, and tracks — all in one place.

---

## Important: Spotify API Access

This application uses the **Spotify Web API**, which operates in **development mode**.

To access the app, your Spotify account **must be registered in the Spotify Developer Dashboard** as an authorized user.

If you want access:

* Contact via WhatsApp: **+57 300 385 5478**
* Share the email associated with your Spotify account
* Your email will be added to the authorized users list

Once added, you'll be able to log in and use the app without restrictions.

## Setup & Installation

### 1. Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* [Git](https://git-scm.com/)

---

### 2. Clone the repository

```bash
git clone https://github.com/peterleunam1/spotify-app
cd spotify-app
```

---

### 3. Install dependencies

```bash
npm install
```

---

### 4. Run in development mode

```bash
ng serve
```

Then open:

```
http://localhost:4200
```

---

### 5. Build for production

```bash
ng build --configuration=production
```

---

### 6. Run tests

```bash
npm run test
```
